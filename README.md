## 🤖 Overview

Onit SideKick is a persistent AI panel on your desktop that helps you write, summarise, translate, and answer questions without leaving your current application.

Whether you're a newcomer or a veteran, Onit SideKick provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Context Aware** | Reads selected text and answers questions about it instantly |
| **Prompt Library** | Save frequently used AI prompts for one-click reuse |
| **Multi-Model** | Switch between GPT-4, Claude, and Gemini in one interface |
| **Sidebar Mode** | Always-visible panel that doesn't interrupt your workflow |
